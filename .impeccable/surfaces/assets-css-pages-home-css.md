# Home page (both sites)

Mode: Read (an index, not a pitch). Shared CSS in `assets/css/standard.css`
(to be folded into the older CSS files); templates live in the consumers
(`mbu/hugo/layouts/index.html`, `scouting-u/hugo/layouts/index.html`).
Job: get a Scout to a badge or rank in one search or one click.

## Direction contract

THESIS: The category standard, played straight: the home page is the index of
everything on the site. It refuses the landing-page arrangement (carousel,
featured cards, "how it works" steps, category icon cards).

OWN-WORLD: Same as the award pages: olive masthead with one gold line, white
page head, gray ground, flat white link tiles with a hairline border and 12px
corners, one sans family. Olive marks our labels, icons and links.

STORY: The Scout sees this is the place for merit badges (or ranks), searches
or picks one by name, and lands on it.

FIRST VIEWPORT: Desktop: masthead (site name, theme toggle, one "Browse"
button; nav links only where a site has a menu); white head with the title,
one lede sentence and a search field with a Search button on the left, and one
photo beside them on the right (the owner chose this from four rendered
options on 2026-11-11); below, the first section heading and a grid of link
tiles (icon or step number, name, requirement count). Phone: no photo; title,
sentence, search, then tiles one per row. Primary action: the search field.

FORM: Category standard (the standing exit), carried over from the
requirements surface. seed:bfbe3f1a510b8ce7.
